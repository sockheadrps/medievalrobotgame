# Dead Code & Cleanup — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove unused files, commented-out code, and debug logging. Flag multiplayer-only code with `// MULTIPLAYER` comments. Do not delete multiplayer code.

**Architecture:** Grep-driven audit followed by targeted deletions. Only remove things confirmed unused. All multiplayer files stay — they get comments, not deletion.

**Tech Stack:** bash/grep for audit. No new dependencies.

**Spec:** `docs/superpowers/specs/refactor/10-dead-code.md`

**This plan runs last — all other plans must be complete and stable first.**

## File Map

**Possibly delete:** unused `.js` and `.py` files found by audit
**Modify:** `RemotePlayer.js`, `RemoteNPC.js`, `ws.py` — add `// MULTIPLAYER` / `# MULTIPLAYER` comments

### Task 1: Audit unused JS files

- [ ] Find JS files that are never imported:
```bash
# List all JS source files
find src/ -name "*.js" | sort > /tmp/all_js.txt

# For each file, check if it's imported anywhere
while IFS= read -r file; do
  basename=$(basename "$file" .js)
  count=$(grep -rl "import.*$basename\|require.*$basename" src/ | grep -v "$file" | wc -l)
  echo "$count $file"
done < /tmp/all_js.txt | sort -n | head -20
```

- [ ] Review the 0-import files. Some may be entry points (loaded by HTML directly) — check:
```bash
grep -rn "RemotePlayer\|RemoteNPC" auxserver/templates/ src/ index.html 2>/dev/null
```

- [ ] Do NOT delete: `RemotePlayer.js`, `RemoteNPC.js` (multiplayer, flagged in Task 4, not deleted)

- [ ] For each genuinely unused file (not an entry point, not multiplayer): confirm with a second grep before deleting.

### Task 2: Audit unused Python files

- [ ] Find Python files that are never imported:
```bash
find auxserver/ -name "*.py" | grep -v ".venv\|__pycache__\|test_" | sort > /tmp/all_py.txt

while IFS= read -r file; do
```

### Task 3: Remove commented-out code blocks

- [ ] Find multi-line comment blocks in Python (5+ consecutive lines):
```bash
grep -rn "^#" auxserver/services/ | awk -F: '{print $1":"$2}' | sort | uniq -c | sort -rn | head -20
# (Rough proxy — look for files with many consecutive # lines)
```

- [ ] Find multi-line comment blocks in JS:
```bash
grep -rn "^//" src/ | awk -F: '{print $1}' | sort | uniq -c | sort -rn | head -20
```

- [ ] For each candidate: read the surrounding context. If it's documentation: keep. If it's dead code (commented-out implementation): delete the block.

- [ ] Also check for outdated implementation docs at the project root:
```bash
ls *.md | xargs grep -l "impl\|plan\|design" | head -10
```
  Candidates: `impl1.md`, `impl2.md`, `impl3.md`, `imple2-design-plan.md`. Read each — if they describe completed work that no longer reflects the codebase, delete them.

- [ ] Commit after each file cleaned:
```bash

git commit -m "cleanup: remove commented-out dead code from <file>"
```

### Task 5: Clean up console.log noise in client code

- [ ] Find console.log calls in client JS:
```bash
grep -rn "console\.log\|console\.debug" src/ | grep -v "console\.warn\|console\.error" | wc -l
```

- [ ] Review each one:
  - Debug/trace logs (e.g., "player pos:", "npc state:", "ws message:") → **delete**
  - Error/warning logs (e.g., "failed to load asset", "connection closed") → **keep**

- [ ] A quick filter: logs inside `if (DEBUG)` or `if (DEV)` guards can stay.

- [ ] Commit after each major file cleaned:
```bash

git commit -m "cleanup: remove noisy debug console.log from client code"
```

### Task 6: Convert Python print() to logging

- [ ] Find print() calls in server code:
```bash
grep -rn "^\s*print(" auxserver/services/ auxserver/api/ auxserver/core/ | grep -v ".venv\|test_"
```

- [ ] For each: replace `print(msg)` with `logger.debug(msg)` or `logger.info(msg)`. Add `import logging; logger = logging.getLogger(__name__)` at the top of any file that doesn't have it.

- [ ] Commit per file:
```bash

```
