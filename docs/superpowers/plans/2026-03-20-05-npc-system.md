# NPC System Consolidation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create `NPCPersonality.js` as the single location for personality metadata, clean up responsibility boundaries in `NPC.js`, `NPCBrain.js`, `NPCTaskRunner.js`, and `ChatBox.js`.

**Architecture:** `NPCPersonality` is a data class holding personality type, emotion state, memory, relationships, and vocabulary. `NPC` holds a reference to its `NPCPersonality` instance. `NPCBrain` decides, `NPCTaskRunner` executes. `DriveSystem` imports personality tables from `NPCPersonality` rather than defining them inline.

**Tech Stack:** Phaser.js 3. No new dependencies.

**Spec:** `docs/superpowers/specs/refactor/05-npc-system.md`

**Prerequisite:** Plan 04 (GameScene split / EntityManager) must be complete.

```javascript
/**
 * NPCPersonality — single source of truth for personality type data and
 * per-NPC runtime state (emotion, memory, relationships, vocabulary).
 *
 * DriveSystem imports DRIVE_GROWTH_RATES, EMOTION_DRIVE_MULTS, and
 * COMMIT_DURATION from here instead of defining them inline.
 */

// Personality type metadata (moved from DriveSystem.js)
export const DRIVE_GROWTH_RATES = {
  // Copy exact values from DriveSystem.js
};

export const EMOTION_DRIVE_MULTS = {
  // Copy exact values from DriveSystem.js
};

export const COMMIT_DURATION = {
  // Copy exact values from DriveSystem.js
};

export const PERSONALITY_TYPES = [
  // List personality type names (copy from NPC.js / LLMClient.js)
];

export default class NPCPersonality {
  constructor(personalityType) {
    this.type = personalityType;

    // Runtime state (moved from NPC.js)
    this.emotion = 'neutral';
    this.memory = [];
    this.relationships = {};
    this.vocabulary = new Set();
    this.phrases = [];
  }

  learnPhrase(phrase) {
    this.vocabulary.add(phrase);
    this.phrases.push(phrase);
  }

  recordMemory(event) {
    this.memory.push({ event, timestamp: Date.now() });
    if (this.memory.length > 50) this.memory.shift(); // cap memory
  }

  updateRelationship(playerId, delta) {
    this.relationships[playerId] = (this.relationships[playerId] ?? 0) + delta;
  }
}
```
